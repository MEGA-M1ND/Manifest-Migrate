Last mile — into Claude

Your zip contains one folder per project, plus a README with these same steps.

  1. Unzip the download on your computer.
  2. In Claude, click Projects → Create project and name it after a folder.
  3. Open the folder and drag its .md files into the project's knowledge panel.
  4. If the folder contains _custom-instructions.md, paste its contents into the project's Set instructions field.
  5. Repeat per project. Start a chat and ask Claude to confirm what context it has.
